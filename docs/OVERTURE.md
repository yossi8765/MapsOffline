# Overture Maps Places מול נקודות העניין של OSM – בדיקה חד-פעמית

תאריך הבדיקה: 2026-11-04. גרסת Overture: **2026-10-21.0** (העדכנית ביותר).
OSM: קובץ `israel-and-palestine-latest.osm.pbf` מ-2026-11-03, ואינדקס החיפוש של האפליקציה (`index.sqlite`, גרסה 3, ובו 75,408 נקודות עניין, כולל נקודות מ-data.gov.il).
שני הצדדים נחתכו לפי פוליגון היבשה של ישראל (+ רמת הגולן) מתוך Overture `division_area`.

## 1. איך מורידים

```
pip install overturemaps duckdb
python -m overturemaps releases latest
python -m overturemaps download --bbox=34.2,29.4,35.95,33.4 -f geoparquet -t place -o places.parquet
```

* זמן ההורדה כ-30 שניות. בתיבה הגאוגרפית יש 264,483 רשומות (51 MB GeoParquet), מתוכן 177,617 בתוך ישראל.
* חלופה: DuckDB ישירות מול `s3://overturemaps-us-west-2/release/2026-10-21.0/theme=places/type=place/*` עם סינון לפי `bbox`.
* מקורות (בתוך ישראל): Meta בלבד – **171,543 (96.6%)**. השאר: Microsoft 2,215, AllThePlaces 2,111, Foursquare 1,507, Uberall 410 ועוד.
* **אין בסכמה שעות פתיחה.** יש טלפונים, אתרים, רשתות חברתיות, מותג, קטגוריה (taxonomy) וציון אמינות (`confidence`).

## 4. רישיון

* בשכבת Places אין רישיון אחד: לכל מקור יש רישיון משלו, לפי דף הייחוס הרשמי (docs.overturemaps.org/attribution).
  * Meta, Microsoft, Uberall, PinMeTo, DAC ו-OpenTravel: **CDLA-Permissive-2.0**. צריך לציין את שם המקור ואת הרישיון.
  * Foursquare: **Apache 2.0**. צריך לצרף את שורת זכויות היוצרים של Foursquare ואת קובץ NOTICE.
  * AllThePlaces: **CC0**.
* בפועל 96.6% מהנתונים הם של Meta תחת CDLA-Permissive-2.0. ברישיון הזה אין דרישת "שיתוף זהה" (share-alike), ומותר להפיץ ולשנות. החובה היא לצרף את נוסח הרישיון ואת הייחוס כשמפיצים את הנתונים עצמם.
* שילוב עם ODbL (OSM): אם מערבבים את נקודות Overture **באותה טבלה** עם נקודות OSM, המאגר המשולב הוא "מאגר נגזר" של OSM, וחלה עליו חובת השיתוף של ODbL. CDLA-P מתיר זאת, אבל זה מסבך את המצב.
* **הדרך הנקייה:** חבילה וקובץ SQLite נפרדים (מאגר אוסף, collective database), שמוצגים לצד OSM בזמן הריצה ולא מתמזגים איתו.
* ייחוס נדרש במסך "אודות" ובמפה: "Places: Overture Maps Foundation (Meta, Microsoft, Foursquare ועוד), CDLA-Permissive-2.0 / Apache-2.0 / CC0".

## 6. מסקנות

* **כמות:** בערים, ב-Overture יש פי 5 עד 10 יותר עסקים מאשר ב-OSM, בעיקר עסקים קטנים כמו מספרות, עורכי דין, נדל"ן וחנויות.
* **טלפון ואתר:** פער עצום לטובת Overture (85% מול 9%), וזה ערך אמיתי למשתמש.
* **דת וחינוך:** OSM טוב יותר. הוא כולל יותר בתי כנסת (1,639 מול 961) ושמות עבריים כמעט תמיד (94% עד 97%).
* **חפיפה:** נמוכה. רק כמחצית מנקודות OSM בתל אביב, וכחמישית בבני ברק ובקריית שמונה, נמצאות ב-Overture. כלומר Overture לא מחליף את OSM, אלא משלים אותו.
* **איכות:** רעש משמעותי מדפי פייסבוק, וכשליש מהשמות אינם בעברית. אין שעות פתיחה. חובה לסנן לפי ציון אמינות.
